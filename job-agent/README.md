# JobAgent - 智能求职助手

一个帮助你梳理工作经历、管理岗位 JD、智能匹配理想职位的 Web 应用。

## 功能

- **我的经历** — 录入基本信息、工作经历（STAR 法则）、技能、项目和教育背景
- **岗位管理** — 添加 JD，自动提取技能关键词，跟踪投递状态
- **智能匹配** — 基于技能重叠度和经验年限计算匹配分数，给出投递建议
- **职业顾问 Agent** — 对话式助手，帮你梳理经历、分析技能、生成简历摘要、准备面试
- **数据导入/导出** — 本地 JSON 备份，数据保存在浏览器 localStorage

## 快速开始

```bash
cd job-agent
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可使用。

## 技术栈

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- localStorage 持久化

## 使用流程

1. 在「我的经历」中填写个人信息和工作经历
2. 在「岗位管理」中添加感兴趣的 JD（可直接粘贴招聘描述）
3. 在「智能匹配」中查看各岗位的匹配度和建议
4. 在「职业顾问」中与 Agent 对话，获取个性化求职建议

## 数据说明

所有数据存储在浏览器本地（localStorage），不会上传到服务器。可通过侧边栏的「导出数据」功能备份，「导入数据」恢复。
