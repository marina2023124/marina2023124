# 对外分享 JobAgent（给朋友 / 面试官）

## 直接可用的公开链接

把下面这个链接发给任何人即可，**不需要**注册 Vercel，也**不需要**向你申请权限：

```
https://marina2023124.vercel.app/try
```

访客打开后点击「加载示例数据并体验」，即可进入应用，数据只保存在访客自己的浏览器里。

---

## 不要分享这些链接

| 链接类型 | 为什么不行 |
|---------|-----------|
| Cursor Cloud Agent 地址 | 只有你能打开，外人无权限 |
| Vercel 项目后台 `vercel.com/.../project` | 需要加入你的 Vercel 团队 |
| Vercel Preview 预览链接（带 Deployment Protection） | 会要求登录 Vercel 或申请访问 |
| `localhost:3000` | 只有你本机能访问 |

## 若 Preview 链接仍要求 Vercel 登录

在 Vercel 项目设置中关闭部署保护：

1. 打开 [Vercel Dashboard](https://vercel.com) → 你的项目
2. **Settings** → **Deployment Protection**
3. 对 Production 保持公开；Preview 若不需要保护可关闭 **Vercel Authentication**

Production 域名 `marina2023124.vercel.app` 默认对公众开放。
